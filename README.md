An entry for the make.fun bounty
[Everyday Things, Two Lines, Longer Run](https://make.fun/bounties/u-suga-everyday-things-two-lines-longer-run-f8734479).

Two lines that explain one everyday thing to a 10-year-old. Line 1 explains a
queue through a single concrete analogy — a train you stand in, where you are
one carriage. Line 2 says honestly what that analogy maps (the single file,
the slow shuffle) and what it leaves out (you are not hooked to anyone; you
can step out whenever you like).

## Run

```sh
python3 main.py
```

Prints the two-line entry (330 characters) and exits 0. The same text is
written to `/output/entry.txt` when that directory is available.
